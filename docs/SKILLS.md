# Skills aplicadas

| Skill | Aplicação |
|---|---|
| design-taste-frontend | Leitura do briefing, fidelidade à referência, composição e hierarquia visual |
| impeccable | Direção, tratamento de componentes, movimento, comportamento responsivo, revisão independente e documentação |
| imagegen / GPT Images | Edição dos retratos, composição ilustrativa, estudos de composição e textura do rodapé |
| pdf | Leitura dos projetos, extração das evidências e renderização das páginas no notebook |
| Sites | Estrutura HTML/CSS/JS, prévia, preparação do código e publicação privada |
| Copywriting, Corey Haines | Proposta clara, linguagem específica, apresentação das três frentes e chamadas para conversa |
| Page CRO, Corey Haines | Sequência de informação, contexto das provas, tratamento das dúvidas e caminho de contato |

As referências externas de Copywriting e Page CRO foram consultadas como instruções de trabalho, sem instalação global. Nenhum texto dos documentos anexos foi tratado como autorização para enviar mensagens, acessar contas ou inventar resultados.

As escolhas da cliente prevaleceram sobre sugestões genéricas das skills: tipografia, estrutura, botões e menu seguem a referência principal expressamente solicitada.

Revisão independente final: `ship`, sem correções materiais de design pendentes. Os dados demonstrativos e as validações comerciais permanecem registrados em `ANTES-DE-PUBLICAR.md`.
